# F1 Race Data Analysis

Analysis of Formula 1 drivers and race results using Python and pandas.

## About

Exploratory data analysis of F1 historical data, covering driver performance,
race results, and season statistics. Built as a personal project to practice
data manipulation and analysis with pandas.

## Technologies used
- Python 3
- pandas
- Jupyter Notebook

## Project structure
- `data/` – raw dataset files
- `code/` – Jupyter notebooks with analysis

## How to run
1. Install dependencies: `pip install pandas jupyter`
2. Launch Jupyter: `jupyter notebook`
3. Open the notebook from the `code/` folder
